# 2026.09.0 — 2026-09-07

First CalVer release. The theme is the web seam: templates and routers stopped doing work that belongs in a service, and the guards that enforce that are now wired and honest.

## Issues Closed

- LUXSWIRL-216 — Import/export API was unauthenticated — `GET /api/v1/import-export/export` returned the full check inventory, including internal hostnames, to any anonymous caller; the two import routes accepted writes the same way. All three now require the API token.
- LUXSWIRL-217 — `POST`/`DELETE /alerts/snooze` were unreachable. `/alerts/{alert_id}` was registered first, so Starlette matched `alert_id="snooze"` and 422'd. The literal routes now register ahead of the parameterised one, with a comment saying why the order is load-bearing.
- LUXSWIRL-214 — The check detail panel's dependency section never rendered: the router dropped `parent_check` on the way to the template.

## Features

- Route-smoke suite (`tests/route_smoke/`): every registered route is requested at least once, so a route that 500s on import or on its first render fails the suite instead of shipping. Seeds its own fixtures and truncates only what it seeded.
- `filterwarnings = error` is now meaningful end-to-end — a `DeprecationWarning` raised inside a handler fails the test rather than being swallowed into a 200.

## Refactors

- **URL assembly moved out of templates.** Agent rows, agent edit/key panels, status pages, jobs, scheduler, users, registration keys, settings, check panels and artifacts all take a URL bundle assembled in the view service. Templates no longer concatenate paths by hand.
- **Display shaping moved to the seam.** The response-time sparkline path, the network-scan panel, synthetic-check timings, the notification form and the public status selector are now shaped in a service and handed to the template as finished values. The pure shapers live in `app/core/` (`sparkline.py`, `scan_panel.py`, `synthetic_timings.py`, `ssl_expiry.py`, `scan_check_names.py`) so tests can import them without reaching into a private view module.
- **Markup out of Python.** The last hand-built HTML strings in service code are gone; forms compose from the field macros, and inline styles are utility classes or SVG attributes.
- **Inline scripts extracted** to modules under `app/static/js/` (`main`, `timeago`, `trace-viewer`, `public-status`, `status-page-public`, `network-scan-detail`, `logo-demo`).
- **Web templates run under `StrictUndefined`.** Every undefined-guard was adjudicated rather than blanket-defaulted; a typo in a template name is now an error, not a silent blank.
- **Check form fields declared once** — `app/web/check_form.py` holds `CheckFormFields` with create/update/clone panels, replacing three near-duplicate parameter lists. Note the dataclass constraint: a subclass cannot make an inherited defaulted field required again, so each panel declares its own identity fields; pinned by `tests/checks/test_check_form_fields.py`.
- **Seventeen superseded service/crud methods removed** (`24e2b80`) — the dead-code sweep went 23 → 6. Each had a live successor reached in production; the evidence per symbol is in LUXSWIRL-218. The six that remain have no successor and are held for an owner decision.

## Error handling

- 55 broad `except Exception` blocks in web routers and 9 more at the view-service seam are gone. They returned a friendly partial at HTTP 200, so a bug reached the user as a normal outcome and monitoring as SUCCESS. The exception now reaches `main.py`'s global handler, which negotiates by request type: `/api/` → JSON, `HX-Request` → empty body plus an error toast with `HX-Reswap: none`, otherwise a full error page. Every site still catches `ValueError`, so validation messages are unchanged.
- The agent's remaining broad catches are dispositioned in place with the reason each one is deliberate (daemon loops that must survive a transient DB error, per-item enrichment that degrades rather than aborts, a health check whose contract is to return False, fail-closed bcrypt verification).
- Definite swallows now record what they discarded.

## Fixes

- **SSL expiry ignored operator settings.** The ingest path looked up `ssl_cert_warning_days` while the keys are registered as `alert.ssl_cert_warning_days`, so it always fell back to the built-in 30/14; the check detail panel then recomputed the flags with 30 and 7 hard-coded, overwriting whatever was stored. Both now read the same settings through `app/core/ssl_expiry.py`.
- **Sparkline emitted invalid SVG** — the path could begin with `L` and no `M`, on roughly a quarter of inputs. Proved by a differential run of the original template expression against the port over 309 series: 236 identical, 73 differing exactly on the broken case, 0 others.
- **`max_retries` on the check form was inert** — the field was named `max_retries` while the handlers read `retry_attempts`.
- **Alert form rendered `Variables: , , ,`** — Jinja was evaluating the `{{NAME}}` placeholders meant to be shown literally.
- **`{{ x.update }}` rendered `<built-in method update…>`** — a dict-backed URL bundle resolves `dict.update` before the key. URL bundles are objects now.
- **API import always 500'd** — the log call passed `extra=result | {...}` where `created` collides with a reserved `LogRecord` attribute.
- **Malformed JSON bodies returned 500 instead of 422** — `exc.errors()` carries raw bytes; the payload is passed through `jsonable_encoder` now.
- **`export-agent-config` never returned** — the response model declared a UUID where the handler returns the agent name.
- **`GET /login` 500'd** under `StrictUndefined` (regression, caught and fixed in-branch).
- Route names were ambiguous between the API and web routers, so some forms posted to `/api/v1`. Names are now unique and asserted by `tests/test_route_names.py`.
- `HTTP_422_UNPROCESSABLE_ENTITY` replaced at 9 sites (deprecated; surfaced once warnings became errors).
- Batched three per-row query patterns into one query each; the dependents list filters in SQL, with a comment on why the remainder stays in Python; the dashboard group's sort row opens once rather than once per branch.
