# Changelog

Per-version **technical** change logs live in
[`apps/backend/app/change_logs/`](apps/backend/app/change_logs/) — one file per
version, e.g. `change_logs/2026.09.0.md`. This file is a pointer, not the content.

For the user-facing view of a release, see [RELEASE_NOTES.md](RELEASE_NOTES.md).

- Format and conventions: [`change_logs/writing-guide.md`](apps/backend/app/change_logs/writing-guide.md)
- Versions are CalVer `YYYY.0M.MICRO`, sourced from the root `VERSION` file.

## Versions
