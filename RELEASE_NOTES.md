# Release Notes

Per-version **user-facing** release notes live in [`apps/backend/app/release_notes/`](apps/backend/app/release_notes/) — one file per version, e.g. `release_notes/2026.09.0.md`. This file is a pointer, not the content.

For the technical/internal view of a release, see [CHANGELOG.md](CHANGELOG.md).

- Format and conventions: [`release_notes/writing-guide.md`](apps/backend/app/release_notes/writing-guide.md)
- Versions are CalVer `YYYY.0M.MICRO`, sourced from the root `VERSION` file.
